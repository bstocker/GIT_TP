# Alle Amar

- Pseudo GitHub : amar78-alt

- Ce que je connais déjà de Git : Je connais les commandes de base comme git add, git commit, git push et git pull.- Ce que j'attends de cet atelier : Apprendre à travailler efficacement en équipe avec Git et GitHub, maîtriser les branches, les commits et la résolution des conflits.## Quiz

1. Juste après `git commit`, où se trouve mon commit ?

Mon commit se trouve dans l'historique local de mon dépôt, dans mon Codespace. Il n'est pas encore envoyé sur GitHub.

2. Juste après `git push`, où se trouve-t-il ?

Mon commit est envoyé sur le dépôt distant GitHub. Les autres collaborateurs peuvent alors récupérer mes modifications.

3. Que se passe-t-il si je supprime mon Codespace après un commit mais sans push ?

Je risque de perdre mes commits et mes modifications locales, car ils n'ont pas encore été envoyés sur GitHub.
