## Quiz

1. Juste après `git commit`, mon commit se trouve dans l'historique local de mon dépôt Git, dans mon Codespace. Il n'est pas encore envoyé sur GitHub.

2. Juste après `git push`, mon commit se trouve sur GitHub, dans le dépôt distant. Les autres membres peuvent le récupérer avec `git pull`.

3. Si je supprime mon Codespace après un commit sans avoir fait de push, je risque de perdre mon commit, car il n'est pas sauvegardé sur GitHub.
